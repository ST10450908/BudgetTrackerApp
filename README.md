# BudgetTrackerApp 

> Android budget tracking app built in Kotlin for OPSC6311 Assignment Part 2

---



##  App Overview

BudgetTrackerApp is a mobile application designed to help users track their income and expenses efficiently. The app provides a simple interface for recording transactions and visualizing spending habits.

---

##  Features

* Add income and expenses
* Categorize transactions (Food, Transport, Entertainment, etc.)
* View all transactions
* Dashboard with summary of spending
* Pie chart visualization of expenses
* User-friendly interface

---

##  Technologies Used

* Kotlin
* Android Studio
* XML (UI Design)
* MPAndroidChart (for data visualization)
* Git & GitHub (Version Control)

---

## Project Structure

* `MainActivity.kt` – App entry point
* `DashboardActivity.kt` – Displays charts and summaries
* `AddTransactionActivity.kt` – Handles adding transactions
* `res/layout/` – UI layouts
* `res/values/` – App resources (colors, strings, styles)

---

##  How to Run the App

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/BudgetTrackerApp.git
   ```
2. Open the project in Android Studio
3. Allow Gradle to sync
4. Run the app on an emulator or Android device
